About Philippine Science High School System - Workshop

Full-Stack Web Development with LAMP and Laravel: Building Scalable Digital Solutions for Centralized Systems

This workshop aims to strengthen the web development kills of PSHS personnel through hands-on activities using Linux, Apache, MySQL, PHP, and Laravel.

Workshop Learning Objectives

  • Understand the fundamentals of web development.
  • Practice Git and GitHub collaboration.
  • Develop web applications using the LAMP stack.
  • Explore Laravel for modern PHP development.
